# Accessibility Testing with Cypress

A practical project focused on learning and implementing web accessibility testing using Cypress.

## Project Status

Currently in progress.

This repository is part of my learning journey toward Accessibility QA and automated accessibility testing.

## Planned Technologies
- Cypress
- JavaScript
- axe-core
- cypress-axe
- WCAG 2.2

## Goals
- Understand WCAG accessibility principles.
- Identify common accessibility barriers.
- Automate accessibility checks.
- Integrate accessibility testing into a Cypress framework.
